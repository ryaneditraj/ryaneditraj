## What I build

**Quantitative research.** Markets treated as a lab you can audit. Each result keeps a trail: walk-forward splits, a score whose points are labeled, and a record of the ideas that were rejected.

**Computer vision.** Detection tied to a review surface. The model writes a timestamped snapshot a person can open on a dashboard.

**Education software.** Tools a student or a teacher can use on a phone. One project is the school day in a single app. Another is a CBSE Class 12 Physics concept predictor aimed at what to study next.

**Plain-language technology.** The same subjects show up on Instagram at [@ryaneditraj](https://instagram.com/ryaneditraj) for a general audience of about 295,000 people. The code stays on GitHub. The explanation stays human.
